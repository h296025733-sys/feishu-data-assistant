# TechWave经营工作台

飞书多维表格“数据表视图插件”，直接读取并在权限允许时写入当前 Base 的原生 `投产比` 表。插件不复制业务表、不生成影子汇总表，也不会在飞书 SDK 不可用时静默切换成演示数据。

## 业务界面

- 店铺汇总行默认名为 `TechWave`；管理员可在工作台右上角“店铺配置”按 Base 修改显示名、汇总名和投产比表名。修改汇总名会同步重写本表公式、重命名汇总记录并复读验证。
- 商品区按商品分组，每个商品固定展示 12 项指标。
- 固定列：产品、指标、合计全部、月合计；日期按月、周、日、星期四层表头组织。
- 默认只展示商品搜索、月份、筛选入口和新增商品；整月/30/90/180 天、只看异常、只看待补收进筛选面板。
- API、人工和公式用指标文字标签区分，不再用大面积多色底纹堆叠；API/人工格可编辑，公式格只读，红色只用于异常，待补使用克制的黄色提示。
- “异常”仅指重复、负数、商品卡超量或公式结果不一致；“待补”沿用原表`检查`字段的`待录入/待补数据`，不把可选低频字段空白误判为异常。
- 本地演示仅通过 `?demo=1` 显式启用，页面会显示“本地演示数据”。

## 数据与写入约束

- 优先按 `src/domain.ts` 内稳定字段 ID 校验；字段 ID 不一致时才检查精确字段名，缺字段会阻止打开。
- 编辑前复读当前格；若已被他人修改，则不覆盖并显示冲突。
- 同一记录的写入串行化；每次只写一个字段，写后立即复读确认。
- 新增商品日记录前检查“正式商品名称＋日期”，新增后复读。并发重复时仅在本插件刚建行仍为空白的前提下撤回该行。
- 商品映射保存在插件 Bridge 配置用于新增校验；TikTok 自动回填仍以机器人中央商品字典为准。

## 本地开发

要求先安装并登录飞书官方 `opdev` CLI。

```powershell
pnpm install
pnpm typecheck
pnpm test
pnpm start
```

开发地址由官方 `BitableAppWebpackPlugin` 输出。`block.json` 已绑定测试 Base 的 `投产比` 表和 `商品录入` 视图。

独立视觉演示：

```text
http://127.0.0.1:8080/block/?demo=1
```

演示模式写入只修改内存，不进入飞书。

## 构建与上传

```powershell
pnpm typecheck
pnpm test
pnpm build
pnpm upload
```

跨企业或换店铺构建时可设置：

```powershell
$env:BUSINESS_DISPLAY_NAME = '新经营主体'
$env:STORE_AGGREGATE_LABEL = '新店铺汇总名'
$env:ROI_TABLE_NAME = '投产比'
pnpm build
```

这三个变量只改变插件运行时名称匹配与显示；目标Base仍须保留兼容字段、公式和视图结构。

当前测试企业应用为 `demo_7ee89be4`，数据表视图能力为 `demo_611ddfc6`。首次上传或创建新版本前，应确认当前 `opdev` 登录企业仍为“测试企业 - Tech-Wave 开发测试”，再按语义化版本号发布。

测试企业使用独立上传包，避免误把正式应用清单传到测试企业：

```powershell
pnpm upload:test
```
